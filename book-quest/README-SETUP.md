# BOOK QUEST テスト運用セットアップ

## 運用設定
- 回答期限：2026年11月19日 23:59（日本時間）
- ニックネーム入力必須
- 回答はGoogleスプレッドシート「回答一覧」に保存
- 期限後は画面とサーバーの両方で受付を拒否

## 1. 回答保存先を作る
1. Googleスプレッドシートを新規作成（例：BOOK QUEST回答集計）。
2. 「拡張機能」→「Apps Script」を開く。
3. このフォルダの Code.gs の内容を貼り付けて保存。
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
5. 実行するユーザー：自分／アクセスできるユーザー：全員、でデプロイ。
6. 初回はGoogleの権限確認を許可。
7. 表示されたウェブアプリURL（末尾 /exec）をコピー。

## 2. サイトに接続
1. config.js を開く。
2. window.BOOKQUEST_ENDPOINT = \"\"; の空欄に、上でコピーしたURLを入れる。
3. config.js をGitHubリポジトリの book-quest/config.js に反映する。
4. GitHub Pagesの公開URLを仲間内に共有する。

## 3. 回答確認・締め切り後の集計
- スプレッドシートの「回答一覧」に送信日時、ニックネーム、Q1〜Q10が1回答1行で追加されます。
- 2026/11/19 23:59（日本時間）を過ぎるとApps Script側でも受付を拒否します。
- ニックネームは公開ページに表示されます。回答シートは共有範囲を管理者のみにしてください。
- 送信内容は自由記述を含みます。結果を公開する際は、本人の許可なく個人が特定される内容を出さないようご注意ください。

## 注意
- このサイトは既存の book-intro-card リポジトリ内の /book-quest/ に配置します。既存の本の紹介カード本体は変更しません。
- Apps ScriptのURL設定が終わるまでは送信できません。公開URLを配布する前に、管理者がテスト送信し、シートに記録されることを確認してください。
- この簡易版はニックネーム単位の重複送信防止は行いません。テストでは1人1回の送信を案内してください。
